# Brand logo slots

Place licensed, official brand SVGs here as `<brand-id>.svg` (e.g. `lexus.svg`, `gmc.svg`, `byd.svg`),
then set `logoFile:'assets/brands/<brand-id>.svg'` for that brand in `data/brands.js`.

Brands currently shown as a text wordmark because no verified vector source was available:
lexus, gmc, geely, changan, jetour, gac, haval, byd.

Use each manufacturer's official brand guidelines. Never substitute another brand's mark or a generic icon.
