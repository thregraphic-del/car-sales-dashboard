# لوحة مؤشرات رضا المتدربين — أمانة منطقة عسير

لوحة تنفيذية تفاعلية من صفحة واحدة (عربية، من اليمين لليسار) تحلل استبيان المتدربين في برنامج التدريب التطوعي.

- `index.html`: اللوحة الجاهزة، ملف واحد مستقل يتضمن البيانات بعد إخفاء الهوية والشعار.
- `src/template.html`: الواجهة وكل منطق الحساب. تُحسب المؤشرات في المتصفح من سجلات المشاركين، ولا توجد قيم ثابتة مكتوبة يدويًا.
- `build/build.py`: يقرأ ملف الردود (xlsx)، ويستبدل عناوين البريد بمعرّف مشفّر غير قابل للعكس، ويحجب الأسماء الواردة في التعليقات، ويربط ملفات الترميز، ثم يُنتج `index.html`.
- `build/coding/q*.txt`: ترميز الموضوعات والنبرة لكل تعليق نصي. كل سطر بالصيغة `رقم_الصف رمز±`، و`+` تعني إيجابي، و`~` محايد أو مختلط، و`-` سلبي، و`0` تعني «لا يوجد».
- `assets/logo-reverse.png`: الشعار الرسمي (النسخة الفاتحة على البني) مقتطع من دليل الهوية دون أي تعديل.

## إعادة البناء

```bash
pip install openpyxl
python3 build/build.py "<مسار ملف الردود>.xlsx"            # صفحة HTML كاملة
python3 build/build.py file.xlsx --fragment --out page.html  # دون غلاف <html> للمستضيفات التي تضيفه
```

لا يُحفظ ملف الردود الأصلي في المستودع لأنه يحتوي على عناوين بريد إلكتروني.
يمكن أيضًا تحميل نسخة أحدث من الملف من داخل اللوحة عبر زر «تحميل ملف محدّث»، وتجري المعالجة في المتصفح فقط.
التعليقات الجديدة التي لم تُرمَّز تظهر بوصف «غير مصنّفة».

## ملاحظات منهجية

تفاصيلها في قسم «المنهجية وجودة البيانات» داخل اللوحة، وأبرزها:
- يحتوي الملف على 227 ردًا، وليس 228.
- لم تُحسب نسبة الاستجابة لأن عدد المستهدفين (1,349) لم يُتحقق منه.
- تكررت 7 عناوين بريد بإجابات مختلفة، وتُبقي اللوحة جميع السجلات افتراضيًا مع خيار لاستبعاد الإرسال الأقدم.
- عبارات السلامة الميدانية لا تتضمن خيار «لا ينطبق».
- أسئلة ما بعد التدريب تخص المتدربين السابقين فقط.
