# n8n Workflow — إشعار مبيعة سيارة جديدة

هذا المجلد يحتوي على Workflow جاهز للاستيراد في n8n، مرتبط ببيانات لوحة `car-sales-dashboard`.

## ماذا يفعل

1. **مراقبة صفوف جديدة (Google Sheets Trigger)** — يفحص شيت المبيعات كل دقيقة، ويُشغَّل عند إضافة صف بيع جديد.
2. **تنسيق بيانات البيع (Set)** — يقرأ الأعمدة (عربي أو إنجليزي) ويحوّلها إلى حقول موحّدة: `customerName`, `brand`, `branchName`, `totalPrice`, `saleDate`, `color`.
3. **إرسال إشعار Slack** — يرسل رسالة بتفاصيل البيعة إلى قناة Slack.
4. **تسجيل في سجل الإشعارات (Google Sheets Append)** — يضيف سطرًا إلى شيت باسم `Notifications` في نفس الملف، لتتبّع كل الإشعارات المُرسَلة.

## خطوات الاستيراد والإعداد

1. في n8n: **Workflows → Import from File** واختر `car-sale-notification.workflow.json`.
2. افتح عقدة **مراقبة صفوف جديدة** واستبدل `PUT_YOUR_GOOGLE_SHEET_ID_HERE` بمعرّف الشيت الفعلي (من رابط الشيت)، واضبط اسم الصفحة (`sheetName`) إن اختلف عن `Sheet1`.
3. اربط بيانات اعتماد Google Sheets الخاصة بك (OAuth2) في كل عقدة Google Sheets.
4. افتح عقدة **إرسال إشعار Slack** واستبدل `PUT_YOUR_SLACK_CHANNEL_ID` بمعرّف القناة، واربط بيانات اعتماد Slack API.
5. أنشئ صفحة جديدة باسم `Notifications` في نفس ملف الشيت (بأعمدة: التاريخ والوقت، العميل، العلامة التجارية، الفرع، السعر الإجمالي) — أو عدّل اسم الصفحة في عقدة **تسجيل في سجل الإشعارات** لتطابق ما لديك.
6. فعّل الـ Workflow (Active).

## ملاحظات

- أسماء الأعمدة في عقدة "تنسيق بيانات البيع" تدعم نفس الأسماء البديلة (Aliases) المستخدمة في `index.html` (`COL_ALIASES`)، لذا يجب أن تعمل مباشرة مع نفس الشيت الذي تقرأ منه لوحة المعلومات عبر Google Apps Script.
- لاستبدال Slack بالبريد الإلكتروني: احذف عقدة Slack وأضف عقدة **Send Email** (Gmail/SMTP) بنفس التعبيرات (`{{ $json.customerName }}` ...).
